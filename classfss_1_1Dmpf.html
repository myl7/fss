class fss::Dmpf< in_bits, max_points, bucket_bits, Group, Prg, Prp, In, ch_lambda >

2-party DMPF scheme.

Gen(), BatchEval(), and EvalAll() are host operations. Cuckoo hashing uses exactly three candidate buckets per input. The PRP permutes [0, 3*kDomainSize), where kDomainSize = 2^in_bits. kBucketCount is the allocated bucket count for max_points. Gen() returns the active bucket count m_rt and bucket-domain size b_size_rt for the actual point count. These runtime values, the PRP seed, and all per-bucket arrays must come from the same successful Gen() call. Evaluation derives its bucket bound from b_size_rt, so it needs b_size_rt but not m_rt; m_rt stays key metadata. The supported point-count interval is [kMinPoints, max_points]. Increasing bucket_bits can lower kMinPoints at the cost of more correction word storage.

Evaluate the DMPF on all input points.

Candidates are routed by the exclusive bucket bound derived from b_size_rt: ceil(3*kDomainSize/b_size_rt). Gen() sizes b_size_rt = ceil(3*kDomainSize/m_rt), so the bound is at most m_rt and is exactly one past the largest bucket index a candidate can reach.

Launch full-domain CUDA evaluation with internal temporary bucket outputs.

The host instance supplies backend values as kernel arguments. Key/output buffers and backend device resources are prepared and retained by the caller. Temporary bucket outputs are allocated and released in the supplied stream. No backend upload, deep copy, or synchronization is performed. Prg, Prp, and Group must support the device execution and concurrency used. This is one multipoint key with ceil(3*kDomainSize/b_size_rt) inner DPF keys, not a batch of independent multipoint keys.

Template Parameters
frontier_depthInner DPF frontier depth, capped at bucket_bits. Defaults to 16.
threads_per_blockInner DPF block size, capped at the frontier width. Defaults to 256. The requested block size is a power of two in [1,1024]. The inner DPF derives its block-root depth, permits at most eight tail levels, and uses signed-int block indices, exactly as Dpf::EvalAllGpuBatch().
Parameters
bParty index, false for party 0 and true for party 1.
sigmaShared PRP seed from successful Gen().
b_size_rtRuntime bucket size from that Gen(). Every located bucket then stays below kBucketCount exactly when b_size_rt is at least ceil(3*kDomainSize/kBucketCount).
s0sDevice storage with this party's seed for each bucket below ceil(3*kDomainSize/b_size_rt).
cwsDevice storage of at least ceil(3*kDomainSize/b_size_rt)*(bucket_bits+1) correction words, in bucket-major order.
ysDevice output storage of at least 2^in_bits int4 blocks, in input order.
streamStream on the device owning the referenced resources.
Precondition
this is accessible on the host. Buffers and backend resources remain valid until work completes.
Returns
The first immediate CUDA allocation, launch, or release failure, or cudaSuccess. Invalid metadata, buffer lengths, null used buffers, or byte sizes return cudaErrorInvalidValue. An unrepresentable merge grid returns cudaErrorInvalidConfiguration. Execution completion is asynchronous.

Generate shared correction words with read-only seeds and one attempt.

Makes one Cuckoo-hashing attempt, then generates each inner DPF. Caller-owned sigma and s0s are preserved.

Retrying a failed attempt
On return 1, draw a fresh uniformly random sigma block from a cryptographically secure random generator and rerun the whole Gen with the same points and payloads. Placement depends on sigma, not on the inner DPF seeds, so s0s need not change for this retry. Incrementing sigma is not resampling. The caller chooses the attempt limit and handles exhaustion. Reuse of the output buffers is allowed. Only a successful call's outputs and its sigma/s0s form a usable key.
Parameters
cwsAt least kBucketCount*(bucket_bits+1) writable correction words in bucket-major order.
m_rtReturned runtime bucket count.
b_size_rtReturned runtime bucket domain size.
sigmaUniformly random PRP seed from a cryptographically secure random generator.
s0sAt least 2*kBucketCount independent uniformly random initial seeds in party-major order: s0s[i] is party 0's seed for bucket i and s0s[kBucketCount+i] is party 1's seed. Sample independently of sigma with a cryptographically secure random generator.
asAlpha values of t point functions.
b_bufsCorresponding beta values, clamped before generation.
tActual number of points in [kMinPoints, max_points].
max_evictionsEviction limit per inserted point. Exceeding it fails the attempt.
Precondition
as.size() >= t and b_bufs.size() >= t.
The first t alpha values are distinct and belong to [0, kDomainSize).
max_evictions is nonnegative.
ceil(3*kDomainSize/cuckoo_hash::ChBucket(t, ch_lambda)) <= 2^bucket_bits.
Exceptions
std::invalid_argumentif cws is shorter than kBucketCount*(bucket_bits+1), s0s is shorter than 2*kBucketCount, t is outside [kMinPoints, max_points], or the bucket size does not fit bucket_bits.
Postcondition
On success, cws, sigma, and s0s define both parties' keys. Correction-word outputs are unspecified on failure. m_rt and b_size_rt may already have been written when the attempt fails; metadata alone is not a key.
Returns
0 on success, or 1 if the Cuckoo-hashing attempt fails.

Estimate the number of buckets for three-choice Cuckoo hashing.
Definition cuckoo_hash.cuh:245

Smallest point count supported by this bucket_bits configuration.

Gen() accepts every t in [kMinPoints, max_points]. The lower bound is at least 30, where the Cuckoo bucket-count estimate applies. Fewer points use fewer buckets and can require a larger per-bucket domain. The capacity condition is ceil(3*kDomainSize/ChBucket(t, ch_lambda)) <= 2^bucket_bits. The shared buffer of correction words contains kBucketCount*(bucket_bits+1)*sizeof(Cw) bytes, so each extra bucket bit adds kBucketCount*sizeof(Cw) bytes without changing the bucket count.
