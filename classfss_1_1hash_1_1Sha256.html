cuda::std::array< int4, 4 > fss::hash::Sha256::Hash ( cuda::std::tuple< int4, const int4 > msg)
inline

Hash a 128+127-bit logical message into two 32B digests.

All 128 bits of a are message data. Bit 0 of b.w is reserved for domain separation; its supplied value is ignored. The other 127 bits of b are message data. Hash a followed by a copy of b with its reserved bit set to 0, then to 1, and concatenate the digests in that order. The input blocks are not modified. Each digest hashes the configured 16B key prefix followed by the two message blocks, for 48B total. This is a prefixed SHA-256 hash.

Parameters
msgTuple of (a, b), with the reserved bit in the second block.
