Detailed Description

GPU full-domain evaluation (EvalAll) for DPF, HalfTree DPF, packed HalfTree DPF, DCF, VDPF (with host-side Prove), and Grotto DCF (Preprocess and EvalAll).

Author
Yulong Ming i@myl.nosp@m.7.or.nosp@m.g

The tree-expansion strategy follows the hybrid approach of GPU-DPF (facebookresearch/GPU-DPF, dpf_hybrid.cu, Z=128): expand the tree toward a frontier of 2^z nodes, then expand each frontier node's subtree down to the leaves. Single kernel launch.

Structure (no redundant expansion):

  • Phase 0: each block walks the b1 top levels to its own subtree root (2^b1 blocks, b1 serial steps per block — negligible).
  • Phase 1: the block breadth-parallel-expands its subtree from depth b1 to depth z in shared memory (one __syncthreads per level, every node expanded exactly once).
  • Phase 2: each thread DFS-expands its own depth-z subtree and converts the last level into leaf outputs.

This keeps the total PRG work at ~2^(n+1) calls (the tree size) instead of the ~n * N of point evals, and avoids the redundant per-thread path re-expansion of a naive breadth-to-z / DFS split.

References

  1. Facebookresearch GPU-DPF: https://github.com/facebookresearch/GPU-DPF
  2. EzPC GPU-MPC: https://github.com/mpc-msri/EzPC (see doc/bench_third_parties.md)

GPU full-domain evaluation of a DMPF key: two launches on the stream.

Phase 1 full-domain-evaluates every active bucket key through DpfEvalAllGpuBatch into the scratch bucket_ys; phase 2 gathers each domain point's kappa Cuckoo buckets. The Prp backend must be device-callable: ChaChaFeistel qualifies, Aes128Feistel does not.

Layouts: s0s and cws follow DpfEvalAllGpuBatch over the m_rt active bucket keys (cws key-major, stride bucket_bits + 1); bucket_ys is caller-allocated scratch of m_rt * 2^bucket_bits int4s; ys holds 2^in_bits outputs.

Template Parameters
zFrontier depth, see DpfEvalAllGpuBatch. Defaults to min(bucket_bits, 16).
b1Block-root depth, see DpfEvalAllGpuBatch. Defaults to the deepest block root that keeps 256 frontier threads when z >= 8; a smaller z runs the whole frontier breadth-parallel in one 2^z block. The phase-1 block size is derived as 2^(z - b1) either way.
Parameters
bParty index. False for 0 and true for 1.
sigmaPRP seed from the key.
m_rtRuntime bucket count stored in the key.
b_rtRuntime bucket size stored in the key.
s0sPer-bucket party seeds (device memory), m_rt entries.
cwsPer-bucket correction words (device memory), key-major.
bucket_ysScratch buffer (device memory), m_rt * 2^bucket_bits int4s.
ysOutput array (device memory), 2^in_bits int4s.
dmpfA Dmpf instance (holds the PRG and PRP).
streamCUDA stream to launch both phases on.
