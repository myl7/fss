Detailed Description

template<int in_bits, int out_bits, typename Prg, typename In = uint, int par_depth = -1>
requires ((std::is_unsigned_v<In> || std::is_same_v<In, __uint128_t>) && in_bits <= sizeof(In) * 8 && Prgable<Prg, 1>)
class fss::PackedHalfTreeDpf< in_bits, out_bits, Prg, In, par_depth >

2-party DPF scheme with packed sub-128-bit outputs, using the Half-Tree construction.

Template Parameters
in_bitsInput domain bit size.
out_bitsOutput width in bits. A power of two within [1, 64]: 128 % out_bits == 0 then holds, so kLanes = 128 / out_bits lanes exactly fill a block. Widths above 64 give a single lane per block and no packing gain; use HalfTreeDpf with its 127-bit group instead.
PrgSee Prgable. Requires mul=1 (CCR hash, 128->128 bits).
InType for the input domain. From uint8_t to __uint128_t.
par_depth-1 is to use ceil(log(num of threads)), which should be good enough. Only EvalAll() uses it. See EvalAll() for details.

Full domain evaluation method.

Evaluate the key on each input, i.e., 0b00...0 - 0b11...1. Store the packed output blocks sequentially: block j covers inputs j * kLanes to (j + 1) * kLanes - 1.

Parameters
bParty index. False for 0 and true for 1. \(i\).
s0Initial seed of the party.
cwsCorrection words returned by Gen().
fcwFinal correction word returned by Gen().
ysPre-allocated output array. Its size must be at least 2 ** kDepth.

Support parallel using OpenMP.
