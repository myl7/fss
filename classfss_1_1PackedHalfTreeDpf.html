Detailed Description

template<int in_bits, int out_bits, typename Hash, typename In = uint>
requires (ValidForInputBits<In, in_bits> && CcrHashable<Hash> && out_bits >= 1 && out_bits <= 64 && (out_bits & (out_bits - 1)) == 0)
class fss::PackedHalfTreeDpf< in_bits, out_bits, Hash, In >

2-party DPF scheme with packed sub-128-bit outputs, using the Half-Tree construction.

Template Parameters
in_bitsInput domain bit size.
out_bitsOutput width in bits. A power of two within [1, 64]: 128 % out_bits == 0 then holds, so kLanes = 128 / out_bits lanes exactly fill a block. Widths above 64 give a single lane per block and no packing gain; use HalfTreeDpf with its 127-bit group instead.
HashUnary CCR hash backend. See CcrHashable.
InType for the input domain. From uint8_t to __uint128_t.

Gen() and scalar Eval() are callable from host and device when the backend supports the execution space and all accessed storage is accessible there. EvalAll() and EvalRange() are host operations. EvalAllGpu() and EvalAllGpuBatch() are host launch methods compiled with a CUDA compiler; they do not run on the device.

Evaluate the packed output block containing x from split Cws.

Layer l is read from cws[l*stride] and the packed-output correction word from cws[kDepth*stride]. The construction carries no control bits, so there is no packed-control parameter. The result contains kLanes consecutive shares; Extract(result, x) reads x's share using the original input x.

Launch full-domain CUDA evaluation for s0s.size() keys from split device Cws.

The batch uses the level-major layout: key k layer l is read from cws[l*stride + k] and key k's packed-output correction word from cws[kDepth*stride + k]. The construction carries no control bits, so there is no packed-control parameter. stride selects the layout. 0 selects the dense level-major layout, in which the stride is the key count of this call. Any other value is a positive stride of at least s0s.size(). Resource and tuning rules match EvalAllGpu(). The batch shares one party index and hash configuration. Every key produces the complete packed domain.

Parameters
bParty index shared by the batch.
s0sDevice storage containing one seed per key.
cwsDevice level-major correction words.
ysDevice key-major rows of 2^kDepth packed output blocks per key.
streamStream on the device owning the referenced resources.
stride0 for the dense level-major layout, where the stride is the key count of this call, or a positive element stride >= s0s.size().
Returns
Immediate CUDA status. Empty batches succeed without reading buffers. Invalid dimensions, null used buffers, strides, or unaddressable counts and bytes return cudaErrorInvalidValue. Oversized grids return cudaErrorInvalidConfiguration.
Precondition
stride is 0 or at least s0s.size().
cws holds at least kDepth*stride + s0s.size() elements, where a stride of 0 counts as s0s.size().
All referenced storage remains alive until the stream work completes.

Extracts the out_bits-bit output share for input x from a packed block.

For full-domain output ys, use Extract(ys[x / kLanes], x). The lane is x % kLanes. Pass the original input x, not the block index. For in_bits = 8 and out_bits = 8, kLanes = 16 and x = 42 selects block 2 and lane 10: Extract(ys[2], 42). For EvalRange() output, x is the relative input index j = input - first. Use Extract(ys[j / kLanes], j).

The out_bits-bit lane value.

Generate split Cws for the packed point function.

Layer l is stored at cws[l*stride] and the packed-output correction word at cws[kDepth*stride]. Tree levels hold the seed correction words and the terminal holds the packed-output correction word exactly as the final Cw entry does. The construction carries no control bits, so there is no packed-control parameter.

Parameters
cwsOutput storage; its capacity includes kDepth*stride+1 elements.
s0sTwo initial seeds, retained by the caller.
aThe secret point. Its low log2(kLanes) bits select the packed lane.
betaOutput value, which must fit in out_bits bits.
stridePositive element stride between layer entries. The default stride of 1 stores the components contiguously.
Precondition
a is in [0, 2^in_bits).
beta <= the out_bits-bit maximum.
stride > 0.
With M = numeric_limits<size_t>::max()/sizeof(int4), stride <= (M-1)/kDepth and cws has at least kDepth*stride+1 elements.
Inputs and outputs do not overlap.
All accessed storage is accessible from the calling execution space.
A beta, stride, or capacity violation aborts with a diagnostic in Debug builds on both the host and the device, and is undefined behavior in Release builds.
Postcondition
cws and s0s[party] form the corresponding party's key.
Only the described prefix is written, and storage beyond it is untouched.
