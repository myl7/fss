Detailed Description

AES-128 MMO PRG using direct AES-NI intrinsics without OpenSSL overhead.

Copyright

Author
Yulong Ming i@myl.nosp@m.7.or.nosp@m.g

Round keys are pre-expanded at construction time. Each Gen() call issues one AES-NI encrypt sequence per output block with no per-call context overhead. Gen8() applies the same construction to 8 independent seeds at once by interleaving 8 streams, one AES round key per 8 aesenc calls, to saturate the AES pipelines of modern x86 CPUs.

Only for host side (x86-64 with AES-NI).
