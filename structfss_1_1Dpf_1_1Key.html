Detailed Description

template<int in_bits, typename Group, typename Prg, typename In = uint>
struct fss::Dpf< in_bits, Group, Prg, In >::Key

One party's key in the aggregate Cw layout: the correction words plus the party's initial seed.

Dmpf stores one of these per bucket as Dmpf::BucketKey; single-point callers pass component arrays to Gen() and Eval() instead of this type.
