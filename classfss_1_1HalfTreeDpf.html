Detailed Description

template<int in_bits, typename Group, typename Hash, typename In = uint>
requires (ValidForInputBits<In, in_bits> && Groupable<Group> && CcrHashable<Hash>)
class fss::HalfTreeDpf< in_bits, Group, Hash, In >

2-party DPF scheme using the Half-Tree construction.

Template Parameters
in_bitsInput domain bit size.
GroupType for the output domain. See Groupable.
HashUnary CCR hash backend. See CcrHashable.
InType for the input domain. From uint8_t to __uint128_t.

Gen() and scalar Eval() are callable from host and device when the backend supports the execution space and all accessed storage is accessible there. EvalAll() and EvalRange() are host operations. EvalAllGpu() and EvalAllGpuBatch() are host launch methods compiled with a CUDA compiler; they do not run on the device.

Evaluate one point from split Cws.

Layer l is read from cws[l*stride] and the terminal from cws[in_bits*stride]. Levels 0..in_bits-2 read only their seed correction word. The final tree level (in_bits - 1) reads SetLsb(HCW, LCW_0) from its layer entry and LCW_1 from bit in_bits-1 of tr; every other bit of tr is ignored. The terminal cws[in_bits*stride] is the output correction word as Cw::s stores it.

xQuery point.

Returns
This party's output share.

Launch full-domain CUDA evaluation for s0s.size() keys from split device arrays.

The batch uses the level-major layout: key k layer l is read from cws[l*stride + k], key k's packed control is tr[k], and key k's terminal is cws[in_bits*stride + k]. Levels 0..in_bits-2 read only their seed correction word, the final tree level (in_bits - 1) reads SetLsb(HCW, LCW_0) from its layer entry and LCW_1 from bit in_bits-1 of tr[k], and every other bit of tr[k] is ignored. stride selects the layout. 0 selects the dense level-major layout, in which the stride is the key count of this call. Any other value is a positive stride of at least s0s.size(). Resource and tuning rules match EvalAllGpu(). The batch shares one party index and hash configuration. Every key produces the complete domain.

Parameters
bParty index shared by the batch.
s0sDevice storage containing one seed per key.
cwsDevice level-major correction words.
trDevice packed control bits, one value per key.
ysDevice key-major rows of 2^in_bits output blocks per key.
streamStream on the device owning the referenced resources.
stride0 for the dense level-major layout, where the stride is the key count of this call, or a positive element stride >= s0s.size().
Returns
Immediate CUDA status. Empty batches succeed without reading buffers. Invalid dimensions, null used buffers, strides, or unaddressable counts and bytes return cudaErrorInvalidValue. Oversized grids return cudaErrorInvalidConfiguration.
Precondition
stride is 0 or at least s0s.size().
cws holds at least in_bits*stride + s0s.size() elements, where a stride of 0 counts as s0s.size().
All referenced storage remains alive until the stream work completes.

Generate split Cws from caller-owned initial seeds.

Layer l is stored at cws[l*stride] and the terminal at cws[in_bits*stride]. Levels 0..in_bits-2 store a plain seed correction word. The final tree level (in_bits - 1) stores SetLsb(HCW, LCW_0) exactly as Cw::s does, and LCW_1 moves out of Cw::extra into bit in_bits-1 of tr. The control component exists only at that level, so every other bit of tr is zero on output. The terminal cws[in_bits*stride] holds the plain output correction word in Cw::s.

Parameters
cwsOutput storage; its capacity includes in_bits*stride+1 elements.
trOutput packed control bits; only bit in_bits-1 is written.
s0sTwo initial seeds, retained by the caller.
aThe secret point.
b_bufOutput value, clamped before conversion to Group.
stridePositive element stride between layer entries. The default stride of 1 stores the components contiguously.
Precondition
a is in [0, 2^in_bits).
stride > 0.
With M = numeric_limits<size_t>::max()/sizeof(int4), stride <= (M-1)/in_bits and cws has at least in_bits*stride+1 elements.
Inputs and outputs do not overlap.
All accessed storage is accessible from the calling execution space.
A stride or capacity violation aborts with a diagnostic in Debug builds on both the host and the device, and is undefined behavior in Release builds.
Postcondition
cws, tr and s0s[party] form the corresponding party's key.
Only the described prefix is written, and storage beyond it is untouched.
