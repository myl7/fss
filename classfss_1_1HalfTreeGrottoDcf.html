Detailed Description

template<int in_bits, typename Hash, typename In = uint>
requires (ValidForInputBits<In, in_bits> && CcrHashable<Hash>)
class fss::HalfTreeGrottoDcf< in_bits, Hash, In >

2-party DCF scheme over F2 from the packed Half-Tree DPF (Grotto construction).

Template Parameters
in_bitsInput domain bit size. Must exceed 7, the levels a 1-bit output block covers.
HashUnary CCR hash backend. See CcrHashable and PackedHalfTreeDpf.
InType for the input domain. From uint8_t to __uint128_t.

Gen() and scalar Eval() are callable from host and device when the backend supports the execution space and all accessed storage is accessible there. Preprocess() and both EvalAll() overloads are host operations. For N = 2^in_bits and B = N/128, preprocessing stores B packed leaf blocks and a parity tree of 2*B-1 bool entries over whole blocks. Tree queries use O(kDepth) XOR operations and no hash calls. Raw scalar Eval() and the leaf-prefix route can give different individual shares. Both parties must use the same route. Raw EvalAll() and preprocessed evaluation use the same leaf-prefix route and give identical shares.

Evaluate all comparison shares on the GPU from split Cws.

Follows the leaf-prefix route, as in the Cw form. Per-party shares are not comparable across routes.

Expands packed blocks, unpacks their bits, and scans their prefix XOR. Layer l is read from cws[l*stride] and the packed-output correction word from cws[kDepth*stride]. The host instance passes its hash value and instance seed to the packed evaluator. Referenced backend resources must already be device-accessible. Packed-block and CUB scan scratch are allocated and released on stream. No backend upload, deep copy, synchronization, or event management occurs.

Parameters
bParty index.
s0This party's seed, passed by value.
cwsDevice correction words, layer l at index l*stride.
ysDevice output of at least 2^in_bits bool entries, in input order.
streamStream used for evaluation, scanning, and temporary storage.
stridePositive stride between Cw entries.
Precondition
stride > 0 and cws holds at least kDepth*stride+1 elements.
Buffers and backend resources remain valid until queued work completes.
Returns
The first immediate CUDA failure, including allocation or release. Invalid buffers/counts return cudaErrorInvalidValue. Work is asynchronous.

Key generation method for split Cws.

Delegates to PackedHalfTreeDpf::Gen() with beta = 1.

Layer l is stored at cws[l*stride] and the packed-output correction word at cws[kDepth*stride]. The construction carries no control bits, so there is no packed-control parameter.

Parameters
cwsOutput storage; its capacity includes kDepth*stride+1 elements.
s0s2 initial seeds. Users can randomly sample them.
aThe secret comparison threshold in [0, 2^in_bits).
stridePositive element stride between layer entries. The default stride of 1 stores the components contiguously.
Precondition
stride > 0.
With M = numeric_limits<size_t>::max()/sizeof(int4), stride <= (M-1)/kDepth and cws has at least kDepth*stride+1 elements.
Inputs and outputs do not overlap.
All accessed storage is accessible from the calling execution space.
Postcondition
cws and s0s[party] form the corresponding party's key.
Only the described prefix is written, and storage beyond it is untouched.

Build packed leaves and their parity tree on the GPU from split Cws.

Reuses PackedHalfTreeDpf::EvalAllGpu(). Layer l is read from cws[l*stride] and the packed-output correction word from cws[kDepth*stride]. The hash value and instance seed are passed as kernel arguments; resources referenced by the hash must already be device-accessible and allow concurrent use. No allocation, upload, deep copy, or synchronization is performed.
