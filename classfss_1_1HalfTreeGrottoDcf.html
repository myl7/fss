Detailed Description

template<int in_bits, typename Prg, typename In = uint, int par_depth = -1>
class fss::HalfTreeGrottoDcf< in_bits, Prg, In, par_depth >

2-party DCF scheme over F2 from the packed Half-Tree DPF (Grotto construction).

Template Parameters
in_bitsInput domain bit size. Must exceed 7, the levels a 1-bit output block covers.
PrgSee Prgable. Requires mul=1 (CCR hash, 128->128 bits), as PackedHalfTreeDpf.
InType for the input domain. From uint8_t to __uint128_t.
par_depthForwarded to PackedHalfTreeDpf, which fixes the Key type. Eval() does not use it.
