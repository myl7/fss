Detailed Description

template<int mul>
class fss::prg::Aes128Mmo< mul >

AES-128 with Matyas-Meyer-Oseas and pre-initialized cipher contexts as a PRG.

Host-only. Device use of Gen() or GenHalf() fails to build with an unresolved-extern error naming fss_host_only_Aes128Mmo_used_in_device_code.

Concurrency: Gen() runs EVP_EncryptUpdate on the ctxs, and copies of an instance share the same ctxs. OpenSSL does not document one ctx as safe for concurrent updates even for full-block no-padding ECB, so Gen() must not run concurrently on instances sharing ctxs. Parallel host evaluation needs a PRG whose Gen() is safe to call concurrently, such as ChaCha or Aes128MmoRaw.
