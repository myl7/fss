Detailed Description

template<typename Scheme>
class fss::OwnedPackedParityTree< Scheme >

Own packed host leaves and their block-parity tree.

This move-only owner does not transfer storage to a GPU. Views borrow both allocations and remain valid while those allocations remain alive.
