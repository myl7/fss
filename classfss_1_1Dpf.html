Detailed Description

requires (ValidForInputBits<In, in_bits> && Groupable<Group> && Prgable<Prg, 2>)
class fss::Dpf< in_bits, Group, Prg, In >

2-party DPF scheme.

Template Parameters
in_bitsInput domain bit size.
GroupType for the output domain. See Groupable.
PrgSee Prgable.
InType for the input domain. From uint8_t to __uint128_t.

Gen() and scalar Eval() are callable from host and device when the backend supports the execution space and all accessed storage is accessible there. EvalRange() and EvalAll() are host operations. EvalAllGpu() and EvalAllGpuBatch() are host launch methods compiled with a CUDA compiler; they do not run on the device.

Evaluate one point using separate correction components.

Root-order packed bit i is the right-control correction at layer i. The correction s LSB is the left-control correction. Layer i is read from cws[i*stride] and the terminal from cws[in_bits*stride], which Gen() writes as a plain int4 with its LSB zero. Packed bits at and above in_bits are ignored.

Parameters

s0This party's seed from generation.
cwsCorrection words, layer i at index i*stride and the terminal at index in_bits*stride.
trPacked right-control bits, bit i for layer i.
xQuery point.
stridePositive stride between correction entries.
Returns
This party's output share.
Precondition
x is in [0, 2^in_bits).
stride > 0.
With M = numeric_limits<size_t>::max()/sizeof(int4), stride <= (M-1)/in_bits and cws has at least in_bits*stride+1 elements.
cws[in_bits*stride].w & 1 == 0.

Launch full-domain CUDA evaluation for s0s.size() keys from split device arrays.

The batch uses the level-major layout: key k layer i is read from cws[i*stride + k], key k's packed control is tr[k], and key k's terminal is cws[in_bits*stride + k]. Packed bit i of tr[k] is the right-control correction at layer i, and the left-control correction is the LSB of the layer's cws entry, exactly as the split form of Gen() writes them. Bits of tr[k] at and above in_bits are ignored. stride selects the layout. 0 selects the dense level-major layout, in which the stride is the key count of this call. Any other value is a positive stride of at least s0s.size(). Uses the same resource, execution, and tuning rules as EvalAllGpu(). All keys share this scheme's backend configuration, and every key produces the whole domain.

Parameters
bParty index shared by the batch.
s0sDevice storage containing this party's seed for each key.
cwsDevice level-major correction words.
trDevice packed right-control bits, one value per key.
ysDevice key-major rows of 2^in_bits output blocks per key.
streamStream on the device owning the referenced resources.
stride0 for the dense level-major layout, where the stride is the key count of this call, or a positive element stride >= s0s.size().
Precondition
stride is 0 or at least s0s.size().
cws holds at least in_bits*stride + s0s.size() elements, where a stride of 0 counts as s0s.size(), and tr holds at least s0s.size() values.
The buffers and referenced backend resources remain valid until work completes.
Returns
Immediate CUDA status. An empty batch succeeds without reading buffers. Invalid dimensions, null used buffers, strides, or unaddressable sizes return cudaErrorInvalidValue; an oversized grid returns cudaErrorInvalidConfiguration. Execution completion remains asynchronous.

Generate correction words in a caller-strided layout and packed control bits.

Layer i is stored at cws[i*stride] and the terminal at cws[in_bits*stride]. tr receives root-order packed right-control bits: bit 0 is the root layer, bit i belongs to layer i, and bits at or above in_bits are zero. The terminal is stored unchanged as a plain int4. The default stride of 1 stores the correction words contiguously.

Parameters
cwsOutput storage; its capacity includes in_bits*stride+1 elements.
trOutput packed right-control bits, with unused bits zero.
s0sTwo initial seeds, retained by the caller.
aThe secret point.
b_bufOutput value, clamped before conversion to Group.
stridePositive element stride between correction-word entries.
Precondition
a is in [0, 2^in_bits).
stride > 0.
With M = numeric_limits<size_t>::max()/sizeof(int4), stride <= (M-1)/in_bits and cws has at least in_bits*stride+1 elements.
Inputs and outputs do not overlap.
All accessed storage is accessible from the calling execution space.
A stride or capacity violation aborts with a diagnostic in Debug builds on both the host and the device, and is undefined behavior in Release builds.
Postcondition
Only the described prefix is written, and storage beyond it is untouched.
