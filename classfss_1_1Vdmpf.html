Batch evaluation method with the Merkle-fold proof.

Parallel-friendly alternative to BatchEval(): same output shares, and the proof replaces the paper's sequential chains with Merkle-style folds. Per bucket, the leaf nodes (hashes of the corrected per-point hashes, in the bucket's canonical (input, hash) order) fold pairwise level by level in fixed kMerkleChunkSize-leaf chunks, an odd trailing node carrying to the next level unchanged; the chunk roots then combine left to right starting from the bucket's hashed cs. The m bucket nodes fold level by level the same way into the final proof, whose last two words stay zero. Every combining step hashes 64B to 32B, so soundness reduces to the pairwise collision resistance of the fold hash exactly like the VDPF Merkle fold; see doc/vdpf_merkle_fold_security.md.

The proof keeps the 64B shape, so Verify() is shared, but chain and fold accumulators produce different proofs: both parties must pick the same one. This host path is the sequential reference; the GPU path folds the same construction and matches it bit-exactly.

Parameters
bParty index. False for 0 and true for 1.
keyThis party's key.
xsInput points to evaluate.
ysOutput shares (pre-allocated, size >= xs.size()). Will be zero-initialized.
piProof output.

Key generation method.

Retries automatically on failure (Cuckoo hashing failed or an inner VDPF Gen failed): up to 128 attempts, each deterministically perturbing sigma and the seeds from the previous one. The effective sigma and seeds of the successful attempt are written back, so after a successful call sigma and s0s hold the values the returned keys carry.

Parameters
k0Key output for party 0.
k1Key output for party 1.
sigmaPRP seed. Users can randomly sample it. Written back with the effective value used by the successful attempt.
s0sm pairs of initial seeds for inner VDPFs. Users can randomly sample them. Written back with the effective seeds used by the successful attempt.
asAlpha values of t point functions.
b_bufsCorresponding beta values. Will be clamped.
tActual number of points (<= max_points).
ch_retryMax Cuckoo hash eviction attempts.
retryWhether to retry with perturbed sigma and seeds on failure. If false, Gen returns 1 immediately after the first failed attempt.
Returns
0 on success, 1 if the first attempt failed (with retry = false) or all 128 attempts failed (with retry = true).
