Detailed Description

template<int in_bits, int max_points, int bucket_bits, typename Group, typename Prg, typename Prp, typename In = uint, int ch_lambda = 80>
struct fss::Dmpf< in_bits, max_points, bucket_bits, Group, Prg, Prp, In, ch_lambda >::Key

DMPF key for one party.

Stores the PRP seed, runtime parameters from Gen, and per-bucket inner DPF keys. Both parties share each bucket's correction words and differ in the seed. Fields support direct access. Field order, padding, and binary serialization are not specified.
