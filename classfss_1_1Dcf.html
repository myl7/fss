template<int in_bits, typename Group, typename Prg, typename In = uint, DcfPred pred = DcfPred::kLt>
requires (ValidForInputBits<In, in_bits> && Groupable<Group> && Prgable<Prg, 4>)
class fss::Dcf< in_bits, Group, Prg, In, pred >

2-party DCF scheme.

Gen() and scalar Eval() support host and device calls when Prg does. EvalRange() and EvalAll() are host operations and support both predicates. EvalAllGpu() and EvalAllGpuBatch() are host CUDA launch methods.

Evaluate one input from a seed and split correction arrays.

Layer l is read from cws[l*stride] and vws[l*stride]. cws carries the left-control correction in its LSB exactly as Cw::s does, and vws holds the group value. The right-control correction is bit l of tr, and the layer LSBs of vws are ignored because the correction is read from tr; bits of tr at or above in_bits are ignored. The terminal is cws[in_bits*stride] = {0,0,0,0} and vws[in_bits*stride] = v_cw_np1, as Gen() writes them.

Parameters
bParty index, false for party 0 and true for party 1.
s0This party's initial seed.
cwsSeed components, with layer l at index l*stride.
vwsGroup-value components, with layer l at index l*stride.
trPacked right-control bits, bit l for layer l.
xInput in the scheme's domain.
stridePositive element stride between layer entries.
Returns
This party's output share for the selected predicate.
Precondition
stride > 0.
With M = numeric_limits<size_t>::max()/sizeof(int4), stride <= (M-1)/in_bits and both arrays have at least in_bits*stride+1 elements.
vws[in_bits*stride].w & 1 == 0.
All accessed storage is accessible from the calling execution space.
A stride, capacity, or terminal violation aborts with a diagnostic in Debug builds on both the host and the device, and is undefined behavior in Release builds.

Launch full-domain CUDA evaluation for s0s.size() keys from split device arrays.

The batch uses the level-major layout: key k layer l is read from cws[l*stride + k] and vws[l*stride + k], key k's packed control is tr[k], and key k's terminal is cws[in_bits*stride + k] = {0,0,0,0} and vws[in_bits*stride + k] = v_cw_np1. cws carries the left-control correction in its LSB exactly as Cw::s does, and the layer LSBs of vws are ignored because the right-control correction is read from tr[k]; bits of tr[k] at or above in_bits are ignored. stride selects the layout. 0 selects the dense level-major layout, in which the stride is the key count of this call. Any other value is a positive stride of at least s0s.size(). Resource and tuning rules match EvalAllGpu(). The batch shares one party index and backend configuration. Every key produces the complete domain.

Parameters
bParty index shared by the batch.
s0sDevice storage containing this party's seed for each key.
cwsDevice level-major seed components.
vwsDevice level-major group-value components.
trDevice packed right-control bits, one value per key.
ysDevice key-major rows of 2^in_bits output blocks per key.
streamStream on the device owning the referenced resources.
stride0 for the dense level-major layout, where the stride is the key count of this call, or a positive element stride >= s0s.size().
Returns
Immediate CUDA status. An empty batch succeeds without reading buffers. Invalid dimensions, buffers, strides or byte sizes return cudaErrorInvalidValue; an oversized grid returns cudaErrorInvalidConfiguration. Work is asynchronous.
Precondition
stride is 0 or at least s0s.size().
Both arrays hold at least in_bits*stride + s0s.size() elements, where a stride of 0 counts as s0s.size().
All referenced storage remains alive until the stream work completes.

Generate split correction arrays from caller-owned initial seeds.

cws receives the seed components and vws the group-value components. Layer l is stored at cws[l*stride] and vws[l*stride]. cws keeps the left-control correction in its LSB exactly as Cw::s does, and vws carries the pure group value with a zero LSB. The right-control bits move out of the v LSBs into tr, bit l for layer l, and unused high bits of tr are zero. The terminal is cws[in_bits*stride] = {0,0,0,0} and vws[in_bits*stride] = v_cw_np1.

Parameters
cwsOutput seed components; its capacity includes in_bits*stride+1 elements.
vwsOutput group-value components, with the same layout as cws.
trOutput packed right-control bits, bit l for layer l.
s0sTwo initial seeds, preserved by this call.
aComparison threshold in the input domain.
b_bufOutput value, clamped before conversion to Group.
stridePositive element stride between layer entries. The default stride of 1 stores the correction words contiguously.
Precondition
a is in the input domain.
stride > 0.
With M = numeric_limits<size_t>::max()/sizeof(int4), stride <= (M-1)/in_bits and both arrays have at least in_bits*stride+1 elements.
Inputs and outputs do not overlap.
All accessed storage is accessible from the calling execution space.
A stride or capacity violation aborts with a diagnostic in Debug builds on both the host and the device, and is undefined behavior in Release builds.
Postcondition
cws, vws, tr and s0s[party] form the corresponding party's key.
Only the described prefix is written, and storage beyond it is untouched.
