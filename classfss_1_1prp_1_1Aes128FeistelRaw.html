Detailed Description

Small-domain AES-128 Feistel PRP for Cuckoo hashing, computed with AES-NI intrinsics.

Bit-exact with Aes128Feistel and host-only like it, but free of OpenSSL and of per-call key schedules: intended for DMPF/VDMPF setup and evaluation paths whose PRP seed stays fixed for the duration of one mapping build.

Small-domain PRP on [0, domain) using 4-round Feistel + cycle-walking.

Bit-exact with Aes128Feistel::Permu. Host-only. Device use fails to build with an unresolved-extern error naming fss_host_only_Aes128FeistelRaw_used_in_device_code.

seed16-byte PRP key. Round keys are expanded on first use per seed and cached, so repeated calls with one seed skip the expansion.
