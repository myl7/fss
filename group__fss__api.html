Per-candidate corrected per-point hashes of one input, in candidate order.

Entry k belongs to candidate k of the input; it stays zero when that candidate locates outside the allocated buckets or repeats an earlier candidate. Prove() and ProveMerkle() re-locate the candidates from sigma, b_size_rt, and the input.

◆ DcfPred

enum class fss::DcfPred
strong

Comparison predicate.

For the input domain \(\sG_{in} = \{0, 1\}^n\) as bits and \(x, a \in \sG_{in}\), \(x < a\) is defined as that the unsigned integer represented by \(x\) is less than that represented by \(a\), i.e., comparison starts from the most significant bit (MSB).

Enumerator
kLt 

\(y = b\) when \(x < a\)

kGt 

\(y = b\) when \(x > a\)

◆ ChBucket()

int fss::cuckoo_hash::ChBucket ( int t,
int lambda )
constexpr

Estimate the number of buckets for three-choice Cuckoo hashing.

Uses the fit in Lemma 5 of the paper, simplified per Remark 1 for t >= 30: e = (lambda + 130 + log2(t)) / 123.5 and m = ceil(e * t). This estimate is monotonic in t.

Parameters
tNumber of elements, at least 30.
lambdaTarget Cuckoo-hashing failure exponent in bits.
Returns
Estimated bucket count m.
Precondition
The estimated bucket count is representable by int.
Exceptions
std::invalid_argumentif t is less than 30.

The common extent N enforces equal lengths at compile time. Dynamic extents are not supported. The result owns its N blocks and does not allocate memory.
