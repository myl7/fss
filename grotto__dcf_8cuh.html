Detailed Description

2-party distributed comparison function (DCF) over F2 from standard DPF.

Yulong Ming i@myl.nosp@m.7.or.nosp@m.g

The scheme is from the paper, Grotto: Screaming fast (2+1)-PC for Z{2^n} via (2,2)-DPFs_ (1: the published version).

Key generation is identical to standard BGI DPF. The comparison functionality emerges from prefix-parity of the DPF control bits: the two parties' control bits of a node XOR to the parity of the leaves below it (Theorem 4 of the paper).

Output shares are in F2 (XOR sharing). Each party holds a single bool per query. For inputs x: share_0 XOR share_1 = 1[alpha <= x].

Evaluation

Eval(b, s0, cws, x) runs the paper's prefix-parity algorithm (Section 4) on x's root-to-leaf path: in_bits PRG calls per query and no preprocessing, the cost of a DPF point evaluation. Preprocess() instead expands the whole domain, about 2^in_bits PRG calls, into a parity segment tree that Eval(tree, x) then queries without PRG calls. It pays off once a key answers more than about 2^in_bits / in_bits queries. The two routes give different shares that reconstruct to the same value only in pairs, so both parties must use the same route.
