Exclusive upper bound on the bucket index of a located candidate.

PrpHash::Locate() maps every candidate with a positive bucket domain size and an int-representable bucket index into [0, choices * n / bucket_size), so the largest such bucket is ceil(choices * n / bucket_size) - 1, and this is the smallest bucket count that covers every located bucket. A candidate outside that interval locates kRejectedBucket instead.

Parameters
nOriginal input domain size, at least 1.
choicesCandidate count per input, at least 1.
bucket_sizePositive bucket domain size carried by a key.
Returns
ceil(choices * n / bucket_size).

Ceiling division of two positive integers, in the wrap-free form.

(num - 1) / den + 1 equals ceil(num / den) for every num at least 1 and den at least 1. The direct form (num + den - 1) / den gives the same value for every in-range input, but wraps in __uint128_t once den exceeds 2^126 with num = 3 * 2^126.

Parameters
numPositive dividend.
denPositive divisor.
Returns
ceil(num / den).

Smallest bucket domain size that keeps every located bucket in range.

A candidate locates at bucket index ceil(choices * n / bucket_size) - 1 at most, so the smallest bucket domain size whose candidates all stay below bucket_count is ceil(choices * n / bucket_count). This is the inverse direction of BucketIndexBound(): it takes the bucket count a caller can allocate and returns the bucket domain size to require of a key.

Parameters
nOriginal input domain size, at least 1.
choicesCandidate count per input, at least 1.
bucket_countPositive number of allocated buckets.
Returns
ceil(choices * n / bucket_count).

constexpr

Test a key's runtime bucket domain size against a configuration.

b_size_rt is exact-transport key metadata, like the correction-word arrays: no entry trusts the caller to pre-validate it, and the entries that do check it deduplicate the bound through this function. A candidate locates at bucket index ceil(choices*n/b_size_rt) - 1 at most, so every located bucket stays below the allocated bucket count exactly when b_size_rt is at least MinBucketSize(n, choices, bucket_count), and a within-bucket input is an index into a bucket of bucket_bits width, so b_size_rt must also fit bucket_bits.

Parameters
b_size_rtBucket domain size carried by a key.
bucket_size_minSmallest usable bucket domain size, e.g. a scheme's kBucketSize.
bucket_bitsBucket domain bit width.
Returns
True when b_size_rt is at least bucket_size_min and is at most 2^bucket_bits.

constexpr int fss::cuckoo_hash::detail::kRejectedBucket = std::numeric_limits<int>::max()
constexpr

Bucket identifier of a rejected candidate.

PrpHash::Locate() returns it when the exact bucket index does not fit int, or when the bucket domain size is zero. It equals INT_MAX, so every caller filter of the form bucket >= bound, whose bound is an int, rejects the candidate.
