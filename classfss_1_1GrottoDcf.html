template<int in_bits, typename Prg, typename In = uint>

class fss::GrottoDcf< in_bits, Prg, In >

2-party DCF scheme over F2 from standard DPF (Grotto construction).

Template Parameters
in_bitsInput domain bit size.
PrgSee Prgable. Must satisfy Prgable<Prg, 2> (same as DPF).
InType for the input domain. From uint8_t to __uint128_t.

Gen() and scalar Eval() are callable from host and device when the backend supports the execution space and all accessed storage is accessible there. EvalAll() is a host operation.

Evaluate a comparison share along x's path from split correction words.

Layer l is read from cws[l*stride] and the terminal from cws[in_bits*stride]. cws keeps the left-control correction in each layer's LSB and tr takes the right-control bits, bit l for layer l; bits of tr at or above in_bits are ignored.

Evaluate all comparison shares on the GPU from split device correction words.

Follows the leaf-prefix route, as in the Cw form. Per-party shares are not comparable across routes.

Layer l is read from cws[l*stride] and tr carries the right-control bits, bit l for layer l, as in the Cw form. The host instance passes its PRG value to the expansion kernel. Temporary scan storage is queried, allocated, and released on stream. No backend upload, deep copy, synchronization, or event management occurs.

Parameters
bParty index.
s0This party's seed, passed by value.
cwsDevice correction words, layer l at index l*stride.
trPacked right-control bits, bit l for layer l.
ysDevice output of at least 2^in_bits bool entries, in input order.
streamStream used for expansion, scanning, and temporary storage.
stridePositive stride between correction entries.
Precondition
stride > 0 and cws holds at least in_bits*stride+1 elements.
Buffers and referenced backend resources remain valid until work completes.
Returns
The first immediate CUDA failure, including allocation or release. Invalid buffers/counts return cudaErrorInvalidValue. Work is asynchronous.

Generate split DPF correction words with beta equal to zero.

Layer l is stored at cws[l*stride] and the terminal at cws[in_bits*stride]. The key is the underlying DPF key, so cws keeps the left-control correction in each layer's LSB and tr takes the right-control bits, bit l for layer l, exactly as the Dpf split layout does.

Parameters
cwsOutput seed components; its capacity includes in_bits*stride+1 elements.
trOutput packed right-control bits, bit l for layer l.
s0sTwo initial seeds, retained by the caller.
aThe secret comparison threshold.
stridePositive element stride between layer entries. The default stride of 1 stores the correction words contiguously.
Precondition
a is in [0, 2^in_bits).
stride > 0.
With M = numeric_limits<size_t>::max()/sizeof(int4), stride <= (M-1)/in_bits and cws has at least in_bits*stride+1 elements.
Inputs and outputs do not overlap.
All accessed storage is accessible from the calling execution space.
Postcondition
cws, tr and s0s[party] form the corresponding party's key.
Only the described prefix is written, and storage beyond it is untouched.

Build a parity tree on the GPU from split device correction words.

Layer l is read from cws[l*stride] and tr carries the right-control bits, bit l for layer l, as in the Cw form. The PRG value is passed to the kernel; any resources it references must already be device-accessible. No allocation, upload, deep copy, or synchronization is performed.

Buffers and backend resources remain valid until queued work completes.
